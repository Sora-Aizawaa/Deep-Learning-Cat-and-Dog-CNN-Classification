# Deep Learning: Cat and Dog CNN Classification

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify images of cats and dogs using TensorFlow and Keras.

## Technologies
- Python
- TensorFlow and Keras
- TensorFlow Datasets
- NumPy
- Matplotlib
- Google Colab

## Dataset
The Cats vs Dogs dataset is loaded using TensorFlow Datasets.

## Model Architecture
The CNN model uses convolutional layers, max pooling, a fully connected layer, dropout, and a sigmoid output layer for binary classification.

## Experiments
The initial experiment produced the following test results:

| Epochs | Test Accuracy | Correct Predictions | Incorrect Predictions |
|---|---:|---:|---:|
| 5 | 84.69% | 1,970 | 356 |
| 10 | 85.30% | 1,984 | 342 |

Increasing training from 5 to 10 epochs improved test accuracy by 0.61 percentage points.

## How to Run
Open the notebook in Google Colab and run the cells in order.
